# Masyarakat SaaS Knowledge Base — Version 3.0

**Status:** BUILD-READY BASELINE

Masyarakat is a multi-tenant SaaS platform for Islamic organisations and communities. It combines public organisation presence, discovery, an information hub, internal operations, and financial governance.

## Core decisions
- Plans: Free, Starter, Professional.
- Trial: 30 days.
- Visibility: Public, Private, Unlisted.
- MVP management rule: one management account actively manages one organisation.
- Community users may follow multiple organisations.
- Online donations: Coming Soon/Post-MVP.
- Prayer Times, Hijri Calendar, Qibla: included SaaS capabilities.
- Legacy modules: retained but explicitly phased.
