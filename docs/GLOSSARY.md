# Glossary

**Organisation:** SaaS tenant.
**Tenant:** Logical data boundary for one organisation.
**Management User:** User authorised to operate an organisation workspace.
**Community User:** User using public/community capabilities and able to follow organisations.
**Membership:** Authorised relationship between user and organisation.
**Entitlement:** Access/limit granted by subscription.
**Permission:** Authorisation to act on a resource.
**Income:** Money recorded as received.
**Expense:** Money recorded as spent.
**Collection:** Purpose-based money gathering activity.
**Budget:** Planned allocation.
**Public/Private/Unlisted:** Organisation visibility states.
