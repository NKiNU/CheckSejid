# Information Hub

Includes announcements/bulletin posts and events. Content lifecycle: DRAFT → PUBLISHED → ARCHIVED, and ARCHIVED → PUBLISHED (republish, ADR-021). Only authorised users manage tenant content; drafts are not public; publication respects organisation visibility.

Posts and events can carry up to 5 images, one marked as the main photo, and upcoming events of public organisations appear on the public homepage (ADR-033).
